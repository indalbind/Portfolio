#  Personal Portfolio Website

A modern, responsive, and futuristic personal portfolio website built using **React + Vite**, styled with **Tailwind CSS v4**, and enhanced with **Framer Motion**, **shadcn/ui**, and custom UI animations.

This project focuses on clean architecture, reusable components, smooth animations, and a premium user experience suitable for a professional developer portfolio.

---

##  Features

-  **Fast & Modern Setup** using Vite + React
-  **Tailwind CSS v4** with custom theme tokens
-  **shadcn/ui & Aceternity-inspired UI**
-  **Animated Navbar** with blur & flip text effects
-  **Fully Responsive** (desktop & mobile)
-  **Futuristic Glassmorphism Navbar**
-  **Custom Google Font (Funnel Display)**
-  **Smooth Animations** using Framer Motion
-  **Reusable & Scalable Components**
-  **Dark Mode Ready (CSS variables)**
